# БиоБарьер — скоринг биобезопасности хозяйства

Статическая витрина экосистемы (GitHub Pages, без бэкенда и сборки): анкета
биобезопасности на 0–100, которую может пройти **кто угодно** — владелец ЛПХ,
практикант, студент, — не только ветеринарный специалист.

**Ключевая фишка — двойной язык:** у каждого вопроса две формулировки,
бытовая («владелец») и терминологическая («профессионал»), переключатель
в шапке анкеты. Ответы хранятся только в localStorage браузера.

**Тон — «зеркало, а не проверка» (v0.3):** честный ответ не должен
ощущаться самооговором. В анкете виден баннер приватности, язык владельца
чищен от «казённого» словаря проверяющих (журнал/разрешение/договор… —
гейтится тестом) и от снисходительных оборотов («кое-как», «как повезёт» —
тоже гейтится). Варианты идут **от лучшего к худшему** — анкета читается
«от нормы к проблеме», а не списком обвинений. Рядом с итогом — шкала 0–100
с зонами и маркером: направление «выше — лучше» задано явно. Печать в PDF
сохраняет цвета светофора (`print-color-adjust: exact`) плюс слова-уровни,
читаемые даже на чёрно-белом принтере.

|---|---|---|---|

| Птица (бройлеры, несушки, родстадло) | 76 | 14 | Филиппины, n=397: 68.5 / 77.2 / 71.2 |

| Молочный КРС | 75 | 14 | Damiaans 2020: итог 48.6 (SD 8.1) |
| Откорм КРС | 74 | 13 | **не существует** — только светофор |
| Овцы и козы | 73 | 14 | **не существует** — только светофор |

Пакеты «мелкое хозяйство», «откорм КРС», «овцы и козы» и «перепела» не
имеют аналогов: Biocheck.UGent и его спутники делают анкеты только для
коммерческих производств. Для них нет даже зарубежного бенчмарка — это
честно отражено в интерфейсе и гейтится тестом.

## Методика

Риск-ориентированный скоринг — реконструкция подхода [Biocheck.UGent]
(Гентский ун-т, Dewulf и соавт.), не копия их анкеты:

- варианты ответа градуированы 0–100, идут от лучшего к худшему;
- категория = среднее отвеченных вопросов (пропуски исключаются честно,
  из числителя и знаменателя);
- итог = взвешенное среднее категорий, Σ весов пакета = 100 (гейтится);
- внешний (занос) и внутренний (внутри) блоки — агрегаты своих категорий;
- светофор: критично < 50 · есть дыры 50–74 · крепко ≥ 75;
- топ-3 слабых блоков с советом «что чинить первым» — ядро отчёта.

Бенчмарки — только опубликованные зарубежные значения, с пометкой
«данные других стран»; российских бенчмарков не существует (источники —
в методологии на странице и футере).

## Запуск и тесты

```bash
node --test tests/bioscore.test.mjs
```

Гейты: двойные формулировки у каждого вопроса, Σ весов = 100, ссылки
на банк без дыр и дублей, бенчмарки в диапазоне, арифметика на
синтетике (ручной расчёт), частичный скор, **золото** — замороженные
тоталы всех пакетов по трём детерминированным паттернам ответов
(`tests/bioscore.reference.json`; дрейф = красный CI), отчёт без
`undefined`/`NaN`, пороги светофора 50/75, тон языка владельца без
слов проверяющего и снисходительных оборотов, объём 60+ вопросов на
пакет, контракты шкалы и печати в `index.html`.
CI гоняет то же самое (`.github/workflows/ci.yml`).

Золото перегенерируется скриптом `scripts/bb_gen_reference.cjs`
(после осознанных изменений банка/весов — перегенерировать и коммитить
вместе с изменением).

## Структура

```
index.html        — витрина: выбор пакета, анкета, результат, методология
bioscore.js       — движок скоринга (UMD: браузер + node --test)
data-shared.js    — банк общих вопросов (60) + категории с советами (17)
data-poultry.js   — пакет «Птица»: специфичные вопросы + веса + бенчмарк
data-pigs.js      — пакет «Свиньи»: …
data-dairy.js     — пакет «Молочный КРС»: …
data-mixed.js     — пакет «Мелкое хозяйство»: … (bench: null)
data-beef.js      — пакет «Откорм КРС»: … (bench: null)
data-smallrum.js  — пакет «Овцы и козы»: … + категория «Выпас и перегоны»
data-quail.js     — пакет «Перепела»: … + категория «Вывод молодняка»
scripts/          — регенерация золота тоталов
vet-ds.css        — дизайн-система экосистемы (копия, синкер)
tests/            — гейты + золотой референс
```
