# БиоБарьер — скоринг биобезопасности хозяйства

Статическая витрина экосистемы (GitHub Pages, без бэкенда и сборки): анкета
биобезопасности на 0–100, которую может пройти **кто угодно** — владелец ЛПХ,
практикант, студент, — не только ветеринарный специалист.

**Ключевая фишка — двойной язык:** у каждого вопроса две формулировки,
бытовая («владелец») и терминологическая («профессионал»), переключатель
в шапке анкеты. Ответы хранятся только в localStorage браузера; по умолчанию
ничего не отправляется.

**Тон — «зеркало, а не проверка» (v0.3):** честный ответ не должен
ощущаться самооговором. В анкете виден баннер приватности, язык владельца
чищен от «казённого» словаря проверяющих (журнал/разрешение/договор… —
гейтится тестом) и от снисходительных оборотов («кое-как», «как повезёт» —
тоже гейтится). Варианты идут **от лучшего к худшему** — анкета читается
«от нормы к проблеме», а не списком обвинений. Рядом с итогом — шкала 0–100
с зонами и маркером: направление «выше — лучше» задано явно. Печать в PDF
сохраняет цвета светофора (`print-color-adjust: exact`) плюс слова-уровни,
читаемые даже на чёрно-белом принтере.

**Бенчмарк России — opt-in (v0.4):** по умолчанию витрина офлайн, как и
прежде. На экране результата — карточка «отправить анонимный итог»: с
согласия и по кнопке уходят только тип хозяйства, итог 0–100, баллы
категорий и — по желанию — федеральный округ и размер поголовья. Имя,
контакты, идентификаторы устройства и сами ответы не отправляются
**конструктивно** (payload — строгий белый список из 10 полей, гейтится
тестом). Итоги складываются в анонимный коллектор (`scripts/collector.gs`,
Google Apps Script + таблица), а на главной живёт секция «Бенчмарк России»:
агрегаты, светофор по стране, разрезы по типам хозяйств — включая ЛПХ — и
«самые тонкие барьеры страны». Пока выборка добровольная и маленькая, это
честно подписано. Активация коллектора — за ~5 минут по
[BENCHMARK.md](BENCHMARK.md).

**Гигиена первого среза (v0.4.1):** коллектор не публикует группы с
n < 3 (по категориям n < 5) — одиночный итог чужого хозяйства не
агрегат; суточный лимит 500 отправок — бот не выжигает таблицу и квоты;
ключи `cats` проверяются по шаблону на обеих сторонах (`__proto__`
не проходит); витрина санирует и экранирует агрегаты ДО innerHTML
(DOM-XSS при подмене коллектора закрыт); JSONP-фолбэк удалён — удалённый
скрипт не исполняется на общем origin хаба; таймаут 10 с и «вернуть
карточку» для отозванного согласия.

**Двор прежде всего (v0.5) — итог научного спора:** экспресс-скрининг
«красные флаги двора» — 12 вопросов, две минуты, счёт флагов вместо
балла (флаг — вариант с баллом ≤ 25, средние ответы не флагаются),
уровни «двор держится / дыры есть / ворота открыты»; ответы скрининга
переезжают в полную анкету без потери прогресса. Три класса весов ЛПХ
вместо 14 ручных: «ворота» = 10 (новые животные, корм и вода, трупы,
контакты между видами), «разнос» = 7 (визитёры, грызуны, тара, ограда,
больные), «порядок» = 5 (транспорт, циклы, мойка, отсеки, лечение);
переход проверен на стабильность (`scripts/bb_weight_stability.cjs`):
тоталы дрейфуют ≤ 1.6 балла, ядро топ-3 «что чинить» выживает, а дворы
в полосе ±2.5 от порога 50/75 прямо видят пометку «между зонами» —
хрупкость порога честнее предупредить, чем подогнать под неё веса.
Из анкеты ЛПХ вырезаны вопросы-фантазии фермерской инфраструктуры
(мойка транспорта на въезде, контроль дезинфекции посевами, «грязный
выезд» в обход чистых зон) — 70 вопросов, всё во дворе достижимо.

**Матрица «вопрос ↔ норма» (v0.6) — правовая основа каждого вопроса.**
Все 157 вопросов банка получили статус: **норма** — прямой пункт
действующего акта (84 вопроса: № 188 птица, № 114 свиньи, № 622 КРС,
№ 774 овцы и козы, № 37 АЧС, № 158 грипп птиц, № 677 биоотходы),
**рама** — общие обязанности владельца по ст. 18 Закона № 4979-1 (8),
**практика** — прямой нормы нет, вопрос о рекомендуемой профилактической
мере (65). Реквизиты сверены по официальным публикациям текстов
(октябрь 2026) — включая свежие замены: № 103 (птица) отменён № 188,
№ 213 (АЧС) — № 37, № 90 (грипп) — № 158, № 626 (отходы) — № 677,
№ 551 (КРС) — № 622; ссылки на отменённое гейтятся тестом («анти-миф»).
Витрины: чипы норм в профи-режиме анкеты, колонка норм в таблице
категорий и отдельная страница [matrix.html](matrix.html) с реестром
актов и фильтрами — для специалистов, без телеметрии.

**Валидация классов A/B/C (v0.6):** виньетная проверка модели на
синтетической выборке с заранее записанными ожиданиями
(`scripts/bb_class_validation.cjs`, гейт в CI, отчёт
[VALIDATION.md](VALIDATION.md)): монотонность ущерба A «ворота» <
B «разнос» < C «порядок» (60.6 / 65 / 75), зернистость вопроса
(один плохой ответ в A стоит 2.0 балла, в C — 1.2), топ-3 «что чинить»
указывает на продырявленный класс, скрининг чувствительнее балла к
концентрированным дырам (12 флагов при идеальном остальном — итог 80.4).
Это не полевая валидация: полярная проверка (скор против реальных
вспышек) — после появления живой выборки бенчмарка.

Пакеты «мелкое хозяйство», «откорм КРС», «овцы и козы» и «перепела» не
имеют аналогов: Biocheck.UGent и его спутники делают анкеты только для
коммерческих производств. Для них нет даже зарубежного бенчмарка — это
честно отражено в интерфейсе и гейтится тестом.

## Методика

Риск-ориентированный скоринг — реконструкция подхода [Biocheck.UGent]
(Гентский ун-т, Dewulf и соавт.), не копия их анкеты:

- варианты ответа градуированы 0–100, идут от лучшего к худшему;
- категория = среднее отвеченных вопросов (пропуски исключаются честно,
  из числителя и знаменателя);
- итог = взвешенное среднее категорий, Σ весов пакета = 100 (гейтится);
- у ЛПХ — три класса весов A/B/C (10/7/5) по роли в эпидемическом
  процессе двора (v0.5); у фермерских пакетов — свои профили рисков;
- скрининг-12 «красные флаги двора» — счёт флагов вместо балла, живёт
  только в браузере и никуда не отправляется;
- внешний (занос) и внутренний (внутри) блоки — агрегаты своих категорий;
- светофор: критично < 50 · есть дыры 50–74 · крепко ≥ 75;
- топ-3 слабых блоков с советом «что чинить первым» — ядро отчёта.

Бенчмарки — только опубликованные зарубежные значения, с пометкой
«данные других стран»; российских бенчмарков не существует (источники —
в методологии на странице и футере).

## Запуск и тесты

```bash
node --test tests/*.mjs   # биоскор + золото + телеметрия v0.4
# или точечно (работает на любой Node):
node --test tests/bioscore.test.mjs tests/telemetry.test.mjs
```

Гейты: двойные формулировки у каждого вопроса, Σ весов = 100, ссылки
на банк без дыр и дублей, бенчмарки в диапазоне, арифметика на
синтетике (ручной расчёт), частичный скор, **золото** — замороженные
тоталы всех пакетов по трём детерминированным паттернам ответов
(`tests/bioscore.reference.json`; дрейф = красный CI), отчёт без
`undefined`/`NaN`, пороги светофора 50/75, тон языка владельца без
слов проверяющего и снисходительных оборотов, объём 60+ вопросов на
пакет, контракты шкалы и печати в `index.html`.
CI гоняет то же самое (`.github/workflows/ci.yml`). Плюс гейты v0.4
(`tests/telemetry.test.mjs`): payload бенчмарка — белый список из 10
полей без единого личного данного, итог целый и band по светофору,
валидация зеркалит коллектор, история прогонов с кэпом и без дублей,
карточка opt-in и секция бенчмарка есть в витрине, но НЕ в печати,
честный копирайт приватности («по умолчанию» вместо «отправки нет»).
Гейты v0.4.1: шаблон id категорий (own-`__proto__` из JSON.parse
отвергается), JSONP удалён из модуля, санитайзер агрегатов в витрине,
пороги малых групп и суточный лимит в коллекторе.
Гейты v0.5: три класса весов {10, 7, 5} с проверенной раскладкой и
Σ = 100, фантазийные вопросы вырезаны из ЛПХ (tr-02/cd-03/ds-04 —
не в профиле, но живы в банке), скрининг — ровно 12 вопросов с
вариантами-флагами и не-флагами, арифметика флагов (12 худших /
0 лучших / 3 смешанных), пороги уровней 0–1/2–4/5+, минимум 8
ответов для уровня (пропуск — не флаг и не «чистота»), отчёт
скрининга без `undefined`/`NaN`, лента скрининга и «между зонами»
в витрине, рендер флагов не зовёт телеметрию.
Гейты v0.6: матрица НПА покрывает весь банк (157/157, без лишних),
статусы norm/frame/practice и обязательные нормы у norm, ссылки только
на реестр с полными реквизитами и источником, **анти-миф** — матрица не
ссылается на отменённые акты (№ 103/104/551/213/90/626) и замены
объявлены, matrix.html и чипы норм в профи-режиме анкеты, и валидация
классов A/B/C запускается из CI и обязана быть зелёной.

Золото перегенерируется скриптом `scripts/bb_gen_reference.cjs`
(после осознанных изменений банка/весов — перегенерировать и коммитить
вместе с изменением).

## Структура

```
index.html        — витрина: выбор пакета, анкета, результат, методология
matrix.html       — матрица «вопрос ↔ норма»: реестр актов + 157 вопросов
                   с фильтрами (для специалистов, без телеметрии)
bioscore.js       — движок скоринга (UMD: браузер + node --test)
telemetry.js      — opt-in бенчмарк: payload/валидация/отправка/агрегаты/история (UMD)
telemetry-config.js — адреса коллектора (пустые = полностью офлайн)
data-shared.js    — банк общих вопросов (60) + категории с советами (17)
data-npa.js       — матрица «вопрос ↔ норма»: реестр 9 действующих актов
                   (сверка 31.10.2026) + статус каждого из 157 вопросов
data-poultry.js   — пакет «Птица»: специфичные вопросы + веса + бенчмарк
data-pigs.js      — пакет «Свиньи»: …
data-dairy.js     — пакет «Молочный КРС»: …
data-mixed.js     — пакет «Мелкое хозяйство»: … (bench: null) +
                   скрининг «красные флаги» и три класса весов (v0.5)
data-beef.js      — пакет «Откорм КРС»: … (bench: null)
data-smallrum.js  — пакет «Овцы и козы»: … + категория «Выпас и перегоны»
data-quail.js     — пакет «Перепела»: … + категория «Вывод молодняка»
scripts/          — регенерация золота тоталов · проверка стабильности
                   весов (bb_weight_stability.cjs) · валидация классов
                   (bb_class_validation.cjs) · collector.gs — коллектор
                   бенчмарка (Apps Script)
VALIDATION.md     — отчёт валидации классов A/B/C на виньетах (генерируется)
BENCHMARK.md      — как включить сбор анонимных итогов за ~5 минут
vet-ds.css        — дизайн-система экосистемы (копия, синкер)
tests/            — гейты (биоскор + матрица НПА + валидация +
                   телеметрия v0.4) + золотой референс
```
