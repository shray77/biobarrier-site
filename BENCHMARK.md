# Бенчмарк России — как включить сбор анонимных итогов

Витрина статическая (GitHub Pages, без бэкенда), поэтому сбор работает через
**Google Apps Script + Google-таблицу** — бесплатно, без сервера, и данные
хозяин проекта видит глазами (можно выгрузить в CSV в любой момент).
Альтернативный совместимый эндпоинт тоже подойдёт: контракт ниже.

Всё, что нужно человеку на сайте: дойти до результата и нажать
«отправить анонимный итог». Без нажатия не уходит ничего — это opt-in.

## Что уходит и что остаётся

Уходит (иначе запись отвергается — белый список в `valid()`):

```json
{
  "v": 1,                     "pkg": "mixed",
  "ts": "2026-10-31",         "total": 62,
  "band": "mid",              "region": "ЦФО",
  "scale": "s",
  "cats": { "arrival": 55, "vermin": 40 },
  "ans": 68,                  "out": 70
}
```

Не уходит **никогда**: имя и контакты (их негде взять), идентификаторы
устройства, IP в данных, сами ответы, режим языка, тексты анкеты.
Скрининг «красные флаги двора» не отправляет вообще ничего — это не
балл, агрегировать его не с чем (v0.5). Матрица «вопрос ↔ норма»
(v0.6, matrix.html и чипы норм в анкете) — статическая страница без
скриптов сбора: реквизиты актов не персональные данные, уносить нечего.
Итог округлён до целого, дата — до дня; регион — 8 федеральных округов
(намеренно грубо, чтобы не сужать выборку до одиночных хозяйств).

## Активация за ~5 минут

1. **Таблица.** Создать новую Google-таблицу, например
   «BioBarrier — бенчмарк». Доступ — только вам.
2. **Скрипт.** В таблице: «Расширения» → «Apps Script». Заменить содержимое
   `Code.gs` файлом [`scripts/collector.gs`](scripts/collector.gs) из этого
   репозитория. Сохранить.
3. **setup().** В редакторе скрипта выбрать функцию `setup` → «Выполнить».
   Разрешить доступ к таблице (запрос появится один раз). В таблице появится
   лист `submissions` с заголовками.
4. **Deploy.** «Развернуть» → «Новое развертывание» → тип «Веб-приложение»:
   - «Выполнять от имени»: **я** (записи идут в вашу таблицу);
   - «Доступ»: **все** (иначе анонимные посетители не смогут отправить итог).
   Скопировать URL вида
   `https://script.google.com/macros/s/…/exec`.
5. **Витрина.** Вписать URL в `telemetry-config.js` (оба поля — один URL):

   ```js
   window.BB_TELEMETRY = {
     submitUrl: "https://script.google.com/macros/s/…/exec",
     statsUrl:  "https://script.google.com/macros/s/…/exec"
   };
   ```

   Закоммитить и запушить — карточка opt-in на экране результата и секция
   «Бенчмарк России» на главной оживут.
6. **Проверка.** Открыть URL в браузере: должен прийти JSON с `"n":0`.
   Пройти анкету на сайте, отправить итог, обновить URL — `n` станет 1,
   а в таблице появится строка.

Если Apps Script обновляется (`collector.gs` менялся) — «Развернуть» →
«Управление развертываниями» → «Изменить» → новая версия.

## Контракт API (для альтернативного коллектора)

- `POST <submitUrl>` — тело `text/plain` c JSON выше. Клиент шлёт `no-cors`
  (непрозрачный ответ), поэтому «отправлено» = «ушло с устройства»;
  серверная валидация обязательна: мусор не должен попадать в таблицу.
  Ссылочный коллектор дополнительно держит суточный лимит (500 записей)
  и проверку шаблона id категорий.
- `GET <statsUrl>` — JSON агрегатов (параметр `callback=Имя` — JSONP
  для ручной проверки в браузере; витрина им не пользуется):

```json
{
  "v": 1, "n": 27, "updated": "2026-10-31T09:00:00.000Z",
  "mean": 58.4, "median": 61.0,
  "dist": { "bad": 6, "mid": 16, "good": 5 },
  "hist": [0, 1, 2, 3, 4, 6, 5, 3, 2, 1],
  "byPkg":    { "mixed": { "n": 9, "mean": 52.3 } },
  "byRegion": { "ЦФО":   { "n": 11, "mean": 60.1 } },
  "byScale":  { "s":     { "n": 14, "mean": 49.8 } },
  "byCat":    { "vermin": { "n": 22, "mean": 41.2 } }
}
```

Витрина спокойно относится к отсутствию полей: нет `byRegion` — не рисует
таблицу округов, нет данных по пакету — не рисует строку.

**Пороги малых групп (k-анонимность):** `byPkg`/`byRegion`/`byScale`
публикуются только при n ≥ 3, `byCat` — при n ≥ 5. Одиночный итог
чужого хозяйства — не агрегат и наружу не выходит; витрина дополнительно
санирует и экранирует всё пришедшее до отрисовки.

## Ограничения, о которых честно говорить

- **Выборка добровольная** — смещение самоотбором неизбежно; на витрине
  это подписано («первая честная картина, а не норма»).
- **Повторные отправки** не дедуплицируются (никаких идентификаторов по
  принципу анонимности): один человек может внести несколько итогов —
  при малых n это заметно, при росте выравнивается.
- **Квоты Apps Script** (бесплатный аккаунт): минуты выполнения в день —
  с запасом; при всплеске трафика агрегат кешируется на 60 секунд, так что
  `GET` дёшев; суточный лимит 500 POST-записей отсекает ботов.
- **Таблица — конфиденциальна при малых n**: доступ только владельцу,
  Google-аккаунт с 2FA; комбинация «округ + размер + пакет + баллы»
  теоретически уникальна, пока записей мало. Наружу — только агрегаты
  с порогами из контракта выше.
- **Удаление записи** — руками из таблицы (строка = одна отправка);
  публикация — только агрегатами, отдельных строк витрина не показывает.
  Порядок описан в `terms.html` (раздел «Приватность»).

## Чеклист перед включением живого URL

1. Переразвернуть Apps Script новой версией `collector.gs` (пороги n ≥ 3/5,
   суточный лимит) — «Развернуть» → «Управление развертываниями» →
   «Изменить» → новая версия.
2. Проверить руками: `GET <url>` отвечает JSON с `"n":0`; отправка из
   витрины доходит, `n` растёт.
3. Таблица — доступ только владельцу, аккаунт с 2FA; раз в неделю
   поглядывать «Исполнения» на аномалии.
4. При всплеске мусорных POST — поднять/опустить `DAY_LIMIT`, строки
   почистить руками.
5. Самохостинг шрифтов (сейчас Google Fonts CDN) — чтобы «без аналитики»
   в `terms.html` было буквальной правдой; `referrer`-мета уже стоит.
6. (Опционально, после выноса инлайнов в `app.js`) — CSP-мета
   `script-src 'self'`.

Известное сведение QA (не чинить, не обещать): авто-тема от
`prefers-color-scheme` нигде не обещана и не нужна — тема только
кнопкой и через localStorage; это решение витрины, а не пропуск.

## Приватность и закон

В записях нет персональных данных по конструкции: обезличенные значения
без идентификаторов. Отправка — только по явному действию человека,
с расписанным списком полей прямо в карточке. Тем не менее при любых
публичных публикациях агрегатов держите формулировку «выборка
добровольная, не репрезентативная» — честность важнее красивых цифр.
